# i3 Window Manager Dotfiles

My personal i3wm configuration files.

## Installation / Sync

```bash
git clone [https://github.com/](https://github.com/)<YOUR-USERNAME>/i3-config.git ~/dotfiles
mkdir -p ~/.config/i3 ~/.config/i3status
ln -sf ~/dotfiles/i3/config ~/.config/i3/config
ln -sf ~/dotfiles/i3status/config ~/.config/i3status/config
